# Security Policy

## Supported versions

Security fixes apply to the latest published release of Pi Honcho. Older releases are not maintained for security updates. Upgrade to the latest release when a fix is available.

## Reporting a vulnerability

Report security issues privately through GitHub Security Advisories:

<https://github.com/giuseppecrj/pi-honcho/security/advisories/new>

Do not open a public issue for a vulnerability. Do not put secrets, credentials, private user data, or exploit details in public issues, pull requests, or discussions.

Include enough detail for maintainers to reproduce the problem: affected version, environment, and steps. Redact secrets and personal data.

## Response expectations

Maintainers review private advisories as soon as practical. You may receive follow-up questions while the report is assessed. When a fix is ready, maintainers coordinate disclosure through the advisory process. Response time depends on severity and available maintainer capacity; this policy does not promise a fixed service-level agreement.
